# Phase 1f Dependency Vulnerability Triage

Date: 2026-07-06  
Scope: High-severity npm audit findings in `ai-assistant-backend` and `my-ai-assistant`.

| Package | Repo | What Pulls It In | Reachable With User-Supplied Input? | Safest Fix | Recommended Action | Applied Result |
|---|---|---|---|---|---|---|
| `@xmldom/xmldom` | Backend | Transitive through `mammoth@1.11.0` for DOCX extraction. App calls `mammoth.extractRawText` in `utils/extractionPipeline.js`. | Needs Review / partially reachable. Attackers can upload DOCX files, so Mammoth receives attacker-controlled Office XML. The specific advisories are XML serialization/injection and recursion issues; the app does not serialize XML directly, but Mammoth's DOCX parsing path is exercised on user files. | Patch bump inside Mammoth's declared range: `0.8.11` -> `0.8.13`. | Fix now. This is a safe transitive patch and protects a file-parsing path that handles uploaded content. | Fixed in backend `package-lock.json`; `npm ls` now resolves `@xmldom/xmldom@0.8.13`. |
| `defu` | Backend | Transitive through direct dependency `better-auth@1.4.18`. | Low practical reachability. No route passes arbitrary request JSON into `defu` defaults. | Patch bump inside Better Auth's declared range: `6.1.4` -> `6.1.7`. | Fix now. Safe patch-level transitive update; no Better Auth major/minor behavior change required. | Fixed in backend `package-lock.json`; `npm ls` now resolves `defu@6.1.7`. |
| `fast-xml-parser` | Backend | Previously transitive through `@aws-sdk/client-s3@3.1000.0` -> `@aws-sdk/core` -> `@aws-sdk/xml-builder@3.972.8`. | Low practical reachability.
